添加到主屏幕（当 App 用）

  1. iPhone：用 Safari 打开本页 → 点底部分享按钮 →「添加到主屏幕」→ 以后点桌面图标全屏玩。
  2. 安卓：用 Chrome 打开 → 菜单 ⋮ →「添加到主屏幕」/「安装应用」。
  3. 完全离线：点上方「保存离线 HTML 文件」，把文件存到手机，用浏览器打开同样能玩，不需要 IPA / APK 签名。
  4. 关于 IPA / APK：本环境没有 Mac 和你的证书，无法直接签出可安装的 IPA；这个离线版就是打包结果 — 如果你有 AltStore 等自签工具，下一步可把此 HTML 作为 WebClip / 壳工程的内嵌页再自签，需要时再单独帮你准备壳工程说明。
